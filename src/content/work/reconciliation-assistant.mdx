## The problem

Reconciliation was slow, manual, and error-prone. Operators worked through long lists by
hand because the existing automation was a black box — when it guessed wrong, no one could
see *why*, so no one trusted it.

> The blocker was never accuracy. It was trust. People won't hand off work they can't audit.

That reframing changed the whole project: the design problem wasn't "match transactions,"
it was "make an automated match something a human can verify at a glance."

## Designing for trust

Because this is an AI product, the hardest design work was making the model *legible*:

- **Confidence, shown honestly** — high-confidence matches auto-apply; anything uncertain
  is queued for a human, never hidden.
- **Explainable matches** — every suggestion shows the signals behind it, so an operator
  can accept or reject in seconds.
- **Human-in-the-loop by default** — the agent proposes; the person decides, and their
  corrections feed back into the model.
